01 / THE MISSIONBIOLOGY, PUT TO WORK

New materials.
New possibilities.

Biology gives us a starting point for engineering the world around us, from functional materials to the systems they make possible.

Matter Fold aims to turn that possibility into useful technology. Our ambition is a new era of biotechnology that expands what we can make, how we make it, and who can build with it. We begin with a focused challenge in computing, while developing knowledge and tools that could open a wider field of material innovation.

More ways to make. More possibilities to build.

02 / OUR FIRST FOCUSMEMORY HARDWARE

THE FIRST THING WE ARE BUILDING

Our first mission:
memory chips.

We are exploring how biologically derived materials can become the active elements of electronic memory.

A memory cell stores information in a distinguishable physical state. Our work investigates how to engineer those states, control them electrically, and connect them to electronic systems. The goal is to progress from experimental materials and individual cells toward integrated memory chips, with repeatable measurements guiding each step.

● Early-stage research. Material behaviour, device performance and integration remain under experimental investigation.

01

Engineer the material

Explore biologically derived materials whose physical properties could be tuned to create measurable memory states.

02

Build the device

Develop electrical interfaces and test how a cell can write, retain and read information through controlled signals.

03

Connect the system

Work toward addressable arrays and chip integration, using the demands of a complete memory system to guide device development.

03 / HOW WE BUILDEXPERIMENT. LEARN. IMPROVE.

Move quickly.
Learn by building.

We focus on useful materials and hardware so ideas can meet practical tests early. Every experiment should resolve a question, sharpen the next design, and bring a working system closer.

01

Start with a useful outcome

Choose a concrete function, define what needs to work, and design experiments around it. A clear engineering problem gives exploration a direction.

02

Run decisive experiments

Build, measure, revise. Test the assumptions that matter most, learn from the results, and carry those lessons into the next version.

03

Design for the whole system

Consider material behaviour, device interfaces and fabrication together. The goal is to connect promising science with technology people can eventually use.

04 / THE LONGER VIEWKNOWLEDGE THAT TRAVELS

A focused beginning.
A wider horizon.

Memory is our first challenge. The wider ambition is to build a foundation for a more inventive, materially abundant world.

As we learn to shape and integrate biological materials, we aim to carry that knowledge into new applications. Our direction is to build capabilities that can compound across projects: better experiments, better tools, and a deeper understanding of how to turn biological function into engineered systems.

NOW / FIRST FOCUS

Memory hardware

Our current mission: develop biologically derived memory chips, beginning with materials, electrical interfaces and experimental memory cells.

NEXT / EXPANSION

Materials and systems

Our wider ambition: apply what we learn to new functional materials and manufacturing approaches that expand the possibilities for building useful systems.

LONG TERM / POSSIBILITY

Therapeutics, in the long run

Our long-term horizon includes bringing accumulated tools and biological engineering knowledge into therapeutics. This is a future direction; our present work is memory hardware.
